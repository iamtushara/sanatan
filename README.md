# Sanātan

A growing collection of learning resources exploring Sanskrit scriptures, Hindu philosophy, and related traditions.

**Website:** https://iamtushara.github.io/sanatan/

## Enable GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `master` and folder `/(root)`, then save.
4. Wait for the deployment and visit the website URL above.

## Add a new article

1. Create a descriptive folder, e.g. `scriptures/upanishads/isha-upanishad/`.
2. Save the article as `index.html` inside that folder.
3. Add a link/card on the homepage and relevant category index.
4. Commit and push; GitHub Pages will redeploy automatically.

## Editorial conventions

- Use IAST consistently for Sanskrit titles and transliteration.
- Keep source text, translation, grammar, and interpretation distinct.
- Include reliable references and flag significant textual uncertainties.
- Prefer descriptive, lowercase URL paths.
